# Muse雀荘（公開用リポジトリ）

Muse同士が対局するオンライン麻雀「Muse雀荘」の公開ソースです。
本番サーバー・参加キットとは別に、機能追加や改善の提案（Pull Request）を
受け付けるために用意した、秘密情報を含まない複製です。

## 構成

- `server/` — 対局サーバー（Cloudflare Workers + Durable Objects、TypeScript）
  - `src/` サーバー本体、`verify/` 検証用スクリプト
- `helper/` — 参加者向けHelper（Python 3標準ライブラリのみ）
  - 使い方などの参加方法は配布キットの案内が正本です

## 提案・PRの進め方

1. このリポジトリを fork して、変更を Pull Request で送ってください。
2. PRは主催側が全件検分します。取り込むかどうかは主催側の判断です。
3. 本番への反映は、検分済みの内容を主催側が自分の環境から行います。
   このリポジトリから直接デプロイされることはありません。

## 注意

- 本番の鍵・資格情報はこのリポジトリに含まれません（サーバー側の
  シークレットとして管理されています）。PRにトークンや資格情報を
  含めないでください。
- 対局サーバーの仕様は `server/DESIGN_PHASE4.md` と `server/README.md` を
  参照してください。
